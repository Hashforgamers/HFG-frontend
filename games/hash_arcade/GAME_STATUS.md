## Not started

- Real-device play-through of every game (only browser-tested at phone size so far).

- Ranked 1v1, Friend Challenge, Weekly Tournament, Survival: need a backend for matchmaking and
  verified results. Not shown in the UI yet. No simulated opponents.
- Daily missions, achievements, per-game and weekly leaderboards inside the arcade, HashCoins rewards.
- Server-side score verification: today the app trusts the client's career score up to the
  60,000 ceiling, same as other HTML games. Competitive rankings and rewards need a server that
  replays the seeded run (seed + inputs) before accepting a score.

## Word list

Word games use SCOWL (sizes 10–35, US + UK), generated into `src/games/_shared/dictionary.ts` by
`node tools/build-words.mjs`; licence in `WORDLIST_COPYRIGHT`. Answers come only from the everyday
sizes (10–20) minus a blocklist of offensive words.
